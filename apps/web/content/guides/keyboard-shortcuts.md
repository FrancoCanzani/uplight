# Keyboard Shortcuts

Uplight supports keyboard shortcuts to speed up your workflow and help you navigate the dashboard more efficiently.

## Available Shortcuts

| Shortcut | Action | Context |
|----------|--------|---------|
| `Cmd+B` or `Ctrl+B` | Toggle sidebar | Global |
| `Cmd+K` or `Ctrl+K` | Create new resource | Context-aware |
| `Cmd+Shift+K` or `Ctrl+Shift+K` | Open monitor quickstart | Monitors page |

**Note:** On macOS, use `Cmd`. On Windows/Linux, use `Ctrl`.

## Context-Aware Shortcuts

### Cmd+K (Create New)

The `Cmd+K` shortcut intelligently creates a new resource based on the current page you're viewing:

- **On Monitors page** - Opens the "Create New Monitor" form
- **On Heartbeats page** - Opens the "Create New Heartbeat" form
- **On Status Pages** - Opens the "Create New Status Page" form

This context-aware behavior means you can quickly create resources without reaching for your mouse or navigating through menus.

### Cmd+Shift+K (Monitor Quickstart)

Press `Cmd+Shift+K` (or `Ctrl+Shift+K` on Windows/Linux) when viewing the Monitors page to open the quickstart dialog. This allows you to:

- **Quickly create HTTP/HTTPS monitors** - Just paste a URL
- **Quickly create TCP monitors** - Enter host and port
- **Skip the full form** - Create monitors with sensible defaults
- **Configure later** - Fine-tune settings after the monitor is created

The quickstart dialog is the fastest way to add new monitors when you need to get something up and running immediately.

## Global Shortcuts

### Cmd+B (Toggle Sidebar)

Press `Cmd+B` (or `Ctrl+B` on Windows/Linux) to quickly show or hide the sidebar. This is useful for:

- Maximizing screen space when viewing monitors or dashboards
- Quickly accessing navigation without moving your mouse
- Switching between different views efficiently

## How Shortcuts Work

### Input Field Protection

Keyboard shortcuts are designed to not interfere with your typing. They automatically:

- **Don't trigger when typing** in text inputs, textareas, or form fields
- **Only activate** when you're navigating the interface
- **Work consistently** across all supported browsers

### Cross-Platform Support

Shortcuts automatically adapt to your operating system:

- **macOS**: Uses `Cmd` key (⌘)
- **Windows/Linux**: Uses `Ctrl` key

You don't need to remember different shortcuts for different platforms - just use what feels natural for your OS.

## Tips for Maximum Productivity

- **Learn one at a time**: Start with `Cmd+K` for quick creation, then add `Cmd+B` to your workflow
- **Muscle memory**: After a few uses, these shortcuts become second nature
- **Combine with mouse**: Don't feel you need to use shortcuts exclusively - use them when they speed up your workflow

## Summary

Keyboard shortcuts in Uplight help you:

- Create monitors, heartbeats, and status pages faster with `Cmd+K`
- Toggle the sidebar for more screen space with `Cmd+B`
- Navigate the dashboard without breaking your flow
